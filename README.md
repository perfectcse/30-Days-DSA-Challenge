# 🚀 30-Day DSA Challenge

The goal is to build strong problem-solving skills through daily practice, understand common DSA patterns, and prepare for technical interviews.

## 🎯 Challenge Goals

- Understand time & space complexity
- Learn reusable DSA patterns
- Maintain daily solutions and notes
- Improve interview problem-solving skills
